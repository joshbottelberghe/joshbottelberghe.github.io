Live services

Small services I run at home and expose through ngrok.

Each dials outbound to ngrok's edge, so requests reach my machines with no inbound port and no public IP. They run on a desktop and a Raspberry Pi pooled behind one endpoint; the static site stays up either way.

browser ──▶ ngrok edge ──┬──▶ desktop ──▶ Go service
                         └──▶ pi ───────▶ Go service
            (the machines dial out; the edge picks one per request)
