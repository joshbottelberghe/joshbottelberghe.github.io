Live services

Small services I run on my desktop and expose through ngrok.

Each dials outbound to ngrok's edge, so requests reach my machine with no inbound port and no public IP. They're live while the desktop is on; the static site stays up either way.

browser ──▶ ngrok edge ──▶ my desktop ──▶ Go service
            (the machine dials out; goes offline when it's off)
