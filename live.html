Live

A dynamic corner of this site, served straight from my desktop.

The rest of this site is static and hosted read-only on GitHub Pages, so it is always up. This page is different: everything in the panel below is generated right now by a small Go program running on my desktop and handed to you through the ngrok-go SDK — the same client-side agent surface I would build on ngrok's Agent team. My machine dials outbound to ngrok's edge and your request rides back down that one connection. No inbound port, no public IP, nothing exposed.

My desktop is powered down right now, so the live panel is offline. The static site you are reading stays up regardless — that split is the whole point.

Why this way: a static edge for durability, a tunnel for the live stuff. Hosting the whole site through the tunnel would tie it to one machine being on; keeping the canonical site on GitHub Pages and reaching for ngrok only where I want something live is the honest split — and it is exactly the agent-reliability problem (reconnect, degrade gracefully, survive the machine going away) that ngrok's Agent team owns.
