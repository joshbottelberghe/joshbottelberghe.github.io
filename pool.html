Endpoint pooling

Several agents, one address, balanced by the edge.

Identical agents claim the same ngrok endpoint. The edge picks one per request, so there is no load balancer to run. Each agent caps its own intake and lowers that cap while its machine is under pressure, which is why the pool's capacity below moves.

              ┌─▶ endeavour-1 ─┐
your browser ─▶ ngrok edge ─┼─▶ endeavour-2 ─┼─▶ one answers, or sheds with 429
              └─▶ pi-1 ─────────┘
      agents gossip over the LAN, so any one of them can report the whole pool
