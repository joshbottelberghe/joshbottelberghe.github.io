Endpoint pooling

Several agents, one address, balanced by the edge.

My gateway runs as several identical agents that all dial out and claim the same ngrok endpoint (joshbottelberghe.ngrok.app). ngrok's edge load-balances across them — no load balancer for me to run. This page fires real requests at the endpoint and tags each response with the agent that served it, so you can watch the distribution live.

              ┌─▶ agent A ─┐
your browser ─▶ ngrok edge ─┼─▶ agent B ─┼─▶ (one of them answers)
              └─▶ agent C ─┘
      kill an agent → its share is picked up by the rest, no downtime

Each bar is one live agent. I scale the pool up and down (and kill agents) from my desktop with systemctl — watch a bar drop to zero and the others absorb its load, then come back when it rejoins. It's live only while my desktop is on.
