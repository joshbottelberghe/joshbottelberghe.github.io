Endpoint pooling

Several agents, one address, balanced by the edge.

My gateway runs as several identical agents that all dial out and claim the same ngrok endpoint (joshbottelberghe.ngrok.app). ngrok's edge load-balances across them — no load balancer for me to run. This page samples the pool: it fires real requests over a rolling 5-second window, tags each response with the agent that served it, and reports the live distribution — each agent's share, its rate, and how evenly the edge is spreading the load.

              ┌─▶ agent A ─┐
your browser ─▶ ngrok edge ─┼─▶ agent B ─┼─▶ (one of them answers)
              └─▶ agent C ─┘
      kill an agent → its share is picked up by the rest, no downtime

Each bar is one agent's share of the last 5 seconds of traffic. I scale the pool up and down (and kill agents) from my desktop with systemctl — kill one and its share falls out of the window while the others pick up the load; balance climbs back toward even as the edge rebalances.
